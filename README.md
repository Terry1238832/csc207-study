# CSC207 互动复习

面向零基础的中文互动复习手册，按 W01–W07 的学习主题组织。

- 13 章、100 个讲解小节
- 13 个可修改输入或逐步追踪的互动实验
- 73 道带提示、答案解释与错题回练的练习
- 20 题综合自测、考前速查、84 个中英术语
- 新增“今日学习”：闭卷回忆、信心记录、示例渐隐、代码补全、独立检验与跨天复习
- 13 张回忆卡、13 个补全练习、13 道新变式题
- 优先到期复习与高信心错误，每轮最多推进一个新概念
- 浏览器本地保存进度，兼容旧版，支持导出和导入记录

“为什么这样学”页面列出检索、间隔、交错、示例渐隐、自我解释与信心反馈的一手研究和适用边界。具体复习间隔是透明的默认建议，尚未针对 CSC207 做随机实验，不承诺固定提分。

`index.html` 包含全部样式、数据和交互代码，无外部运行依赖。直接用浏览器打开即可离线使用，也可以通过 GitHub Pages 访问。

演示对预设代码与输入进行语义模拟，不提供任意 Java 代码编译。此项目是学习辅助材料，不是官方试卷或完整学期范围；正式考试范围以课程公告为准。

## 发布

GitHub Pages 从 `main` 分支的根目录发布。更新 `index.html` 并推送到 `main` 后，GitHub 会自动更新网站。

本仓库仅包含重新编写的互动手册，不包含原课件 PDF、本地提取文件或个人学习记录。
